# ViewDigest

Gemini의 **영상 이해(Video Understanding)** 기능으로 YouTube 영상을 분석해,
"영상을 보지 않아도 내용을 파악할 수 있는" 수준의 상세 리포트를 만들어주는
Chrome 확장프로그램(Manifest V3)입니다.

## 1. 소개

일반적인 유튜브 요약 도구는 "이런 사건이 있었다", "이런 논란이 있었다" 수준의
피상적인 요약만 제공하는 경우가 많습니다. 이 확장프로그램은 그와 다르게,

- 6하 원칙(누가/언제/어디서/무엇을/왜/어떻게)에 기반한 구체적인 사실 관계
- 인물의 실제 발언(직접/간접 인용)과 뉘앙스
- 구체적인 수치·통계·모델명·기간 등 팩트
- 챕터(1.) → 소주제(1-1.) → 상세 포인트 2~4개의 계층적 구조

를 갖춘 **상세 분석 리포트**를 생성하는 것을 목표로 합니다.
YouTube 시청 페이지에 분석 버튼을 추가해 원클릭으로 리포트를 생성합니다.

### 핵심 특징

- 🎯 **원클릭 분석**: YouTube 시청 페이지의 "⚡ 영상 분석" 버튼 클릭 한 번, 결과는 새 탭에 실시간 표시
- 📡 **채널 구독**: 관심 채널을 등록해두면, 새 영상이 올라올 때마다 자동으로 분석
- 🗂 **히스토리 관리**: 분석 결과를 최대 50개까지 자동 저장, 언제든 다시 열람·삭제
- 💰 **비용/사용량 추적**: 모델별 예상 비용 계산, 일일 사용 횟수 제한(rate limit)으로 과금 폭탄 방지
- 🌙 **다크 모드 UI**: 긴 리포트도 눈이 편하게, 팝업/옵션 페이지 모두 다크 테마 기본 적용
- 🌐 **한국어·영어 지원**: 화면은 브라우저 언어를 따르고, 리포트 언어는 설정에서 고를 수 있음

## 2. 설치 방법

이 저장소는 스토어에 배포된 확장프로그램이 아니라, 소스 코드를 직접 "압축해제된
확장프로그램(Unpacked extension)"으로 Chrome에 로드해서 사용합니다.

1. 이 저장소를 클론하거나 ZIP으로 다운로드한 뒤 압축을 풉니다.
   ```bash
   git clone <이 저장소 URL>
   ```
2. Chrome 주소창에 `chrome://extensions`를 입력해 확장프로그램 관리 페이지로 이동합니다.
3. 화면 우측 상단의 **"개발자 모드"** 토글을 켭니다.
4. **"압축해제된 확장프로그램을 로드합니다"** 버튼을 클릭합니다.
5. 방금 클론/압축 해제한 프로젝트의 **루트 폴더**(`manifest.json`이 있는 폴더)를 선택합니다.
6. 확장프로그램 목록에 **"ViewDigest"**가 나타나고, 브라우저 툴바에
   보라색 아이콘이 추가되면 설치가 완료된 것입니다.
7. 코드를 수정했다면, `chrome://extensions` 페이지에서 이 확장프로그램의 **새로고침(⟳) 아이콘**을
   눌러 변경사항을 반영하세요. (background.js/utils 변경 시 특히 필요)

> 아이콘을 툴바에서 바로 보고 싶다면, 확장프로그램 아이콘 목록에서 압정(📌) 모양을 눌러 고정하세요.

## 3. API 키 발급 방법

이 확장프로그램은 여러분의 개인 Gemini API 키를 사용해 직접 Google에 요청을 보냅니다
(별도의 중계 서버가 없습니다). 따라서 사용 전에 API 키를 먼저 발급받아야 합니다.

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 Google 계정으로 로그인합니다.
2. **"Create API key"** (또는 "API 키 만들기") 버튼을 클릭해 새 키를 생성합니다.
   - 기존 Google Cloud 프로젝트가 없다면 자동으로 새 프로젝트가 생성됩니다.
3. 생성된 키 문자열(`AIza...`로 시작)을 복사합니다.
4. Chrome 툴바에서 확장프로그램 아이콘을 클릭 → 팝업 우측 상단의 **⚙(설정)** 버튼을 클릭해
   옵션 페이지를 엽니다. (또는 `chrome://extensions` → 이 확장프로그램의 "세부정보" → "확장 프로그램 옵션")
5. **"Gemini API 키"** 섹션의 입력란에 키를 붙여넣고 **"API 키 저장"**을 클릭합니다.
6. **"연결 테스트"** 버튼을 눌러 키가 유효한지 바로 확인할 수 있습니다. (이 테스트는 영상 분석을
   수행하지 않는 가벼운 확인 요청이라 별도 비용이 들지 않습니다.)

키는 `chrome.storage.sync`에 저장되어, 같은 Google 계정으로 로그인한 다른 기기의
Chrome에도 자동 동기화됩니다.

> ⚠️ API 키는 절대 다른 사람과 공유하거나 공개 저장소에 커밋하지 마세요. 키가 유출되면
> 제3자가 여러분의 할당량/과금으로 API를 사용할 수 있습니다.

## 4. 주요 기능 설명

### 4.1 영상 분석

YouTube 시청 페이지(`youtube.com/watch?v=...`)를 열면 제목 아래와 오른쪽 추천 영상
목록 위, 두 곳에 **"⚡ 영상 분석"** 버튼이 나타납니다. 버튼을 누르면:

1. 결과 탭(`results/results.html`)이 새로 열립니다.
2. 오늘의 일일 사용 한도를 초과하지 않았는지 먼저 확인합니다.
3. Gemini API에 영상 URL을 `fileData`로 전달해 분석을 요청합니다.
   (영상을 직접 업로드하지 않고 URL만 전달합니다.)
4. Gemini가 생성하는 대로 리포트가 결과 탭에 실시간으로 이어서 표시되고,
   완료되면 자동으로 히스토리에 저장됩니다.

확장프로그램 팝업의 **"🔍 지금 분석하기"** 버튼으로도 같은 분석을 시작할 수 있습니다.
팝업은 분석 시작과 히스토리·사용량 확인만 담당하고, 리포트 표시는 결과 탭이 맡습니다.

**영상의 해당 장면으로 이동**: 소주제 제목 옆의 **▶ 12:34** 버튼을 누르면 그 내용이 나오는
장면으로 갑니다. 그 영상이 열려 있는 YouTube 탭이 있으면 그 탭으로 전환해 재생 위치만 옮기고
(다른 영상 탭은 건드리지 않음), 없으면 그 시각에서 시작하는 새 탭을 엽니다. 시각은 Gemini가
영상을 보고 적은 값이라 몇 초에서 수십 초 어긋날 수 있고, 시각을 확신하지 못한 소제목에는
버튼이 없습니다. 이 기능이 생기기 전(1.2.0 이전)에 만든 리포트에는 시각이 없으므로, 필요하면
"다시 분석"을 누르세요.

### 4.3 히스토리

- 분석이 끝날 때마다 결과(제목/채널 이름/URL/리포트 본문/모델/예상 토큰·비용/생성 시각)가
  자동으로 저장되며, **최대 50개**까지 보관됩니다. 50개를 넘으면 가장 오래된 항목부터
  자동으로 삭제됩니다. 리포트가 길어 히스토리가 약 6MB를 넘을 때도 오래된 항목부터 정리해,
  브라우저 저장 공간 한도(10MB)에 막혀 새 분석이 저장되지 못하는 일이 없게 합니다.
- 채널 자동 분석 알림은 최근 5개까지만 알림 센터에 남기고 오래된 것은 지웁니다.
- 팝업의 **"히스토리"** 탭에서 과거 분석 목록(제목/날짜/채널 이름)을 확인하고, 항목을 클릭하면
  "현재 분석" 탭으로 이동해 해당 리포트를 다시 볼 수 있습니다.
- **영상 하나당 한 항목만** 둡니다. 이미 분석한 영상에서 분석 버튼을 누르면 새로 분석하지
  않고 저장된 리포트를 보여주며(비용이 다시 들지 않음), 안내 옆과 리포트 아래의
  **"🔄 다시 분석"** 버튼으로 새로 분석하면 이전 결과를 새 결과로 바꿉니다. 이 규칙 이전에
  쌓인 중복 항목은 업데이트 후 한 번 정리됩니다(같은 영상은 가장 최근 결과만 남김).
- 각 항목의 🗑 버튼으로 개별 삭제가 가능하며, 옵션 페이지의 **"히스토리 전체 삭제"** 버튼으로
  한 번에 모두 지울 수도 있습니다(확인 창 표시).
- 리포트 보기 화면에서 **복사**(클립보드) / **Markdown 다운로드**(`.md` 파일) / **다시 분석**
  버튼을 제공합니다.
- 복사·다운로드한 리포트 끝에는 `원본 영상: [제목](URL)`과 `Made with [ViewDigest](웹스토어 링크)`가
  붙습니다. 받는 사람이 원본 영상을 찾을 수 있게 하기 위한 것으로, 옵션 페이지 **분석 설정**의
  "복사·다운로드할 때 원본 영상과 출처 링크 포함"을 끄면 리포트 본문만 복사됩니다.
- 분석이 3번 성공하면, 막 끝난 분석 화면 오른쪽 아래에 웹스토어 리뷰를 부탁하는 작은 카드가
  한 번 뜹니다. **리뷰 남기기**(스토어 리뷰 페이지 열기)나 **다시 보지 않기**를 누르면 다시 묻지
  않고, **나중에**를 누르면 분석이 10번 더 성공한 뒤에 한 번만 더 묻습니다. 저장된 리포트를 다시
  열 때는 뜨지 않습니다.

### 4.4 비용 관리

- `utils/cost.js`에 모델별 100만 토큰당 대략적인 입력/출력 단가가 정의되어 있어,
  분석이 끝날 때마다 실제 사용된 토큰 수(Gemini 응답의 `usageMetadata` 기준)로 예상 비용을
  계산해 기록합니다.
- 팝업의 **"사용량"** 탭과 옵션 페이지에서 **오늘/이번 달 분석 횟수와 예상 비용**을 확인할 수
  있습니다.
- 분석 하나하나의 모델과 예상 비용은 결과 탭 제목 아래의 채널 이름에 마우스를 올리면 보입니다.
- **일일 사용 횟수 제한(rate limit)**: 기본값은 하루 20회이며, 옵션 페이지에서 원하는 값으로
  변경할 수 있습니다. 변경 사항은 저장 즉시 다음 분석부터 반영됩니다.
- 한도를 초과하면 분석 요청 자체가 API 호출 전에 차단되어, 불필요한 비용이 발생하지 않습니다.

> 💡 표시되는 비용은 참고용 추정치입니다. 정확한 청구 금액은 Google AI Studio/Cloud
> Console의 결제 대시보드에서 확인하세요.

### 4.5 모델 선택

옵션 페이지에서 세 가지 모델 중 하나를 선택할 수 있습니다.

| 모델 | 특징 |
|---|---|
| `gemini-3.7-flash` | 기본값. 속도와 분석 품질의 균형 |
| `gemini-3.8-flash` | 더 높은 품질(고성능), 비용도 더 높음 |
| `gemini-3.5-flash-lite` | 가장 경제적인 모델, 간단한 영상에 적합 |

### 4.6 채널 구독 (새 영상 자동 분석)

특정 영상이 아니라 **채널 전체를 구독**해두면, 그 채널에 새 영상이 올라올 때마다
자동으로 분석되어 히스토리에 쌓입니다.

1. 옵션 페이지의 **"채널 구독 (새 영상 자동 분석)"** 섹션에서 채널 URL, `@핸들`,
   또는 채널 ID(`UC...`)를 입력하고 **"채널 추가"**를 클릭합니다.
2. 확장프로그램이 (별도의 YouTube API 키 없이) 해당 채널의 공개 RSS 피드를 주기적으로
   확인해 새 영상을 감지합니다. 기본 확인 주기는 30분이며, **"확인 주기(분)"**에서
   원하는 값(최소 5분)으로 바꿀 수 있습니다. **"지금 확인"** 버튼으로 즉시 확인해볼 수도
   있고, 다음 자동 확인 예정 시각이 그 아래에 표시됩니다.
   - YouTube RSS는 멀쩡한 채널에도 한동안 404를 돌려주는 일이 있습니다. 그러면 업로드
     재생목록 RSS, 그다음 채널의 "동영상" 탭 페이지 순으로 대신 읽습니다. 채널 페이지로
     읽은 경우 채널 목록에 "RSS 대신 채널 페이지에서 읽음"이 붙습니다.
   - 모든 경로가 실패하면 채널 목록에 실패 시각과 사유(예: `RSS HTTP 404`)가 빨간색으로,
     그 아래에 마지막 성공 시각이 표시됩니다. 설정 페이지를 열어 둔 채여도 확인 결과가
     바로 반영됩니다.
3. 새 영상이 발견되면 자동으로 "지금 분석하기"와 동일한 파이프라인으로 분석이 진행되고,
   완료되면 다음 두 가지로 알려줍니다.
   - **브라우저 알림**: 알림을 누르면 그 리포트가 새 탭에서 열립니다.
   - **툴바 아이콘의 숫자 배지**: 아직 확인하지 않은 자동 분석 개수입니다. 팝업을 열거나
     리포트를 열면 줄어들고, 팝업 히스토리에는 새 항목에 **NEW**가 붙습니다. 배지는
     아이콘을 툴바에 고정(📌)해 두어야 보입니다.
4. 채널 목록의 체크박스로 채널별 자동 분석을 켜고 끌 수 있고, 🗑 버튼으로 구독을
   완전히 해제할 수 있습니다.

**동작 방식에 대해 알아두면 좋은 점**

- **소급 분석되지 않습니다**: 채널을 등록하는 시점의 최신 영상은 자동 분석 대상이
  아니라 "기준선"으로만 기록됩니다. 그 시점 *이후*에 새로 올라오는 영상부터 자동
  분석됩니다.
- **브라우저가 켜져 있을 때만 확인**합니다. Chrome/Whale이 꺼져 있는 동안 올라온
  영상은, 다음에 브라우저를 켰을 때 알람이 다시 실행되면서 확인됩니다.
- **일일 사용 한도(rate limit)를 함께 소모**합니다. 채널 자동 분석도 수동 분석과
  동일한 하루 횟수 제한을 공유합니다. 한도를 다 쓰면 자동 분석은 잠시 건너뛰고,
  다음 확인(한도가 초기화된 이후)에 자동으로 다시 시도합니다.
- **같은 영상은 두 번 분석하지 않습니다.** 영상 하나를 분석할 때마다 진행 상황을 바로
  저장하므로 확인이 도중에 끊겨도 끝난 영상은 다시 분석하지 않고, 히스토리에 이미 있는
  영상(직접 분석한 영상 포함)은 자동 분석에서 건너뜁니다. 분석이 몇 분씩 걸리는 동안
  브라우저가 백그라운드 작업을 멈추지 않도록 깨어 있게 합니다.
- **분석하지 못하면 알림으로 알려줍니다.**
  - 일일 한도 초과, API 키 없음: 하루에 한 번만 알립니다. 해당 영상은 건너뛰지 않고,
    원인이 해결된 뒤 다음 확인 때 다시 분석합니다. 알림을 누르면 설정 페이지가 열립니다.
  - 시간이 지나면 풀릴 수 있는 실패는 바로 포기하지 않고 **24시간 동안 확인할 때마다 다시
    시도**합니다. 아직 공개 전인 프리미어·라이브, 업로드 직후 처리 중이라 Gemini가 영상을
    가져오지 못하는 경우(403), 서버 과부하(429·5xx), 네트워크 오류, 응답 시간 초과(영상 분석
    10분·YouTube 목록 30초)가 그렇습니다. 그동안 설정
    화면의 채널 목록에 "다시 시도 중"(노란색)으로 표시되고, 24시간이 지나도 안 되면 그때 실패로
    기록하고 알립니다.
  - 그 밖의 실패(영상이 너무 김, Gemini 오류 등): 영상마다 원인을 알립니다. 그 영상은
    다시 시도하지 않으며, 알림을 누르면 YouTube 영상이 열려 분석 버튼으로 직접 다시
    시도할 수 있습니다. 알림을 놓쳐도 설정 화면의 채널 목록에 **최근 실패 3건**(시각, 영상
    제목, 사유)이 7일 동안 빨간색으로 표시됩니다.
  - "다시 시도 중"이나 실패로 표시된 영상도 어떤 경로로든(자동 재시도, 직접 분석) 분석에
    성공하면 그 즉시 목록에서 사라집니다.
- 브라우저가 오래 꺼져있다 켜져서 한 채널에 새 영상이 한꺼번에 여러 개 쌓여있으면,
  **한 번에 확인할 때마다 최대 3개까지만** 자동 분석합니다. (한 채널이 전체 일일
  한도를 독점하는 것을 방지하기 위함이며, 3개를 넘는 나머지는 소급 분석되지
  않습니다.)

### 4.7 화면 언어와 리포트 언어

- **화면 언어**(버튼, 메뉴, 설정, 오류 메시지)는 브라우저 언어를 따릅니다. 한국어 브라우저에서는
  한국어, 그 밖의 언어에서는 영어로 표시됩니다. 문구는 `_locales/ko`와 `_locales/en`의
  `messages.json`에 있습니다.
- **리포트 언어**는 옵션 페이지의 "리포트 언어"에서 고릅니다.

| 설정 | 리포트 언어 |
|---|---|
| 자동 (기본값) | 브라우저 언어가 한국어면 한국어, 그 밖에는 영어 |
| 한국어 | 항상 한국어 |
| English | 항상 영어 |

영상에서 쓰인 언어와는 관계없습니다. 영어 영상을 한국어 리포트로, 한국어 영상을 영어 리포트로
받을 수 있습니다. 언어마다 프롬프트 전체가 따로 있습니다(`utils/prompt.js`).

## 5. 사용 시 주의사항

- **API 키는 사용자 본인 소유**입니다. 이 확장프로그램은 별도의 백엔드 서버 없이 브라우저에서
  Google Gemini API로 직접 요청을 보내며, 발생하는 모든 API 비용은 여러분의 Google 계정으로
  청구됩니다.
- **표시되는 비용은 추정치**입니다 (`utils/cost.js`의 단가는 참고용 근사치이며 공식 요금표와
  다를 수 있습니다). 실제 청구 금액은 반드시 Google 측 결제 대시보드에서 확인하세요.
- **일일 한도(rate limit)는 이 브라우저/프로필 내부에서만 집계**됩니다. 여러 기기·프로필에서
  같은 API 키를 사용하면 실제 Google API 사용량은 이 확장프로그램이 파악하는 횟수보다 많을 수
  있습니다.
- **비공개 영상·연령 제한 영상·저작권 등으로 접근이 제한된 영상**은 Gemini가 내용을 가져오지
  못해 분석이 실패하거나 부정확할 수 있습니다.
- **저작권**: 분석 리포트는 원본 영상의 요약/2차 저작물입니다. 리포트를 외부에 공유·재배포할 때는
  원본 영상의 저작권 및 이용 정책을 준수하세요.
- **히스토리는 로컬(`chrome.storage.local`)에 저장**됩니다. 브라우저 프로필 데이터를
  삭제하거나 확장프로그램을 제거하면 히스토리도 함께 사라집니다. 중요한 리포트는 Markdown
  다운로드 기능으로 별도 백업해두는 것을 권장합니다.
- YouTube가 페이지 구조(DOM)를 변경하면 분석 버튼이 일시적으로 표시되지 않을 수 있습니다.
  이 경우 페이지를 새로고침하거나 확장프로그램을 업데이트해주세요.
- 확장프로그램을 업데이트하거나 다시 로드하면, 그 전에 열려 있던 YouTube 탭의 분석 버튼은
  **"🔄 새로고침 필요"**로 바뀝니다(브라우저가 기존 탭의 스크립트와 확장프로그램의 연결을 끊기
  때문). 버튼을 한 번 더 누르거나 페이지를 새로고침하면 다시 정상 동작합니다.
- 분석 실패(라이브 방송 중인 영상 등)나 채널 목록을 불러오지 못한 경우는 알림·설정 화면에서
  알려 주며, 확장프로그램 관리 페이지의 "오류"에는 남기지 않습니다. 그곳에 오류가 보이면
  예상하지 못한 문제이니 내용을 알려 주세요.
- **채널 구독은 브라우저가 켜져 있을 때만 동작**하며, 수동 분석과 일일 한도를 공유합니다.
  구독 채널이 많거나 업로드가 잦으면 한도가 채널 자동 분석만으로 빠르게 소진될 수 있으니,
  옵션 페이지의 사용량 요약을 주기적으로 확인하세요.
- 개인정보 처리 방식은 [개인정보처리방침](./PRIVACY_POLICY.md)을 참고하세요.

## 7. 사용된 권한

| 권한 | 용도 |
|---|---|
| `storage` | 설정, 분석 히스토리, 구독 채널, 사용량 기록 저장 |
| `tabs` | 현재 YouTube 탭 확인, 팝업에서 분석 시작, 분석 결과 탭 열기 |
| `alarms` | 채널 구독 새 영상을 주기적으로 확인 |
| `notifications` | 채널 자동 분석 완료·실패 시 알림 표시 (누르면 리포트나 설정 페이지 열기) |
| `host_permissions: youtube.com` | YouTube 시청 페이지에 분석 버튼 삽입, 영상 탭 탐색, 채널 RSS 피드/페이지 조회 |
| `host_permissions: generativelanguage.googleapis.com` | Gemini API 호출 |

## 8. 개발 메모

- `background.js`는 `utils/*.js`의 ES 모듈을 `import`하므로, `manifest.json`의
  `background.type`이 `"module"`로 설정되어 있어야 합니다.
- `content.js`는 일반 스크립트(non-module)로 주입되므로 `utils/*.js`를 직접 import할 수
  없습니다. Gemini 호출 등 무거운 로직은 항상 `background.js`를 거칩니다.
- 메시지 액션 이름: `analyzeVideo`(popup → background), `openResultsTab`(content →
  background), `analysisComplete` / `analysisError`(background → popup 브로드캐스트),
  `checkChannelsNow` / `refreshChannelCheckAlarm`(options → background).
- `utils/channels.js`는 background.js(service worker, DOMParser 없음)에서도 동작해야 하므로
  채널 페이지 HTML과 RSS XML을 정규식으로 직접 파싱합니다.
- 화면 문구를 추가할 때는 `_locales/ko`와 `_locales/en`의 `messages.json` 두 곳에 같은 키로
  넣습니다. HTML은 `data-i18n="키"`(텍스트), `data-i18n-title`, `data-i18n-placeholder`,
  `data-i18n-html`(링크가 든 문장) 속성으로 표시하면 `localizePage()`가 채웁니다. JS에서는
  `t("키", 치환값…)`을 씁니다. `content.js`는 모듈이 아니므로 `chrome.i18n.getMessage`를 직접 씁니다.
- 스토어에 업데이트를 배포하는 절차(버전 올리기, `scripts/package.sh`, 대시보드 제출, 태그)는
  `STORE_LISTING.md`의 "업데이트 배포 절차"에 있습니다.
